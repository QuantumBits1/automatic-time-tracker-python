# Introduction
Welcome to the Automatic Time Tracker Python project. This tool helps you track the time you spend on various tasks automatically.

# Dependencies
- Python 3.x
- pandas
- numpy

# How-To
1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/automatic-time-tracker-python.git
    ```
2. Navigate to the project directory:
    ```sh
    cd automatic-time-tracker-python
    ```
3. Install the required dependencies:
    ```sh
    pip install -r requirements.txt
    ```
4. Run the application:
    ```sh
    python main.py
    ```
